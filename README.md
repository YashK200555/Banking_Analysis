Banking Analysis SQL Project

Project Overview

The *Banking Analysis SQL Project* focuses on managing and analyzing banking data using SQL and MySQL. It explores customer details, account balances, transactions, bank branches, and loan information to practice SQL queries and derive useful insights from banking data.

Project Objectives

* Analyze customer information and account details.
* Examine account balances and account types.
* Analyze deposits, withdrawals, and transaction amounts.
* Explore loan amounts and interest rates.
* Practice SQL queries to retrieve and analyze banking data.
* Use SQL functions to summarize and compare banking information.

Tech Stack

* Database: MySQL
* SQL Tool: MySQL Workbench
* Language: SQL

Database Tables

The project uses the following tables:

| Table Name     | Description                                                      |
| -------------- | ---------------------------------------------------------------- |
| Customers    | Stores customer details, email, phone number, and date of birth. |
| Accounts     | Contains account types, balances, and customer information.      |
| Transactions | Stores transaction dates, amounts, types, and account IDs.       |
| Branches     | Contains bank branch names, addresses, and phone numbers.        |
| Loans        | Stores loan amounts, interest rates, and loan dates.             |

SQL Concepts Covered

* Database and table creation
* CREATE, ALTER, DROP, and DESCRIBE
* INSERT, UPDATE, and SELECT
* Primary keys, foreign keys, and constraints
* Filtering using WHERE, IN, BETWEEN, and LIKE
* Sorting using ORDER BY
* Aggregate functions: SUM(), AVG(), MIN(), MAX(), and COUNT()
* String functions: UPPER(), LOWER(), LENGTH(), and CONCAT()
* Date functions: CURDATE(), NOW(), YEAR(), MONTH(), and DATEDIFF()
* Conditional functions: CASE, IF(), and IFNULL()
* GROUP BY and HAVING
* Joins: INNER JOIN and LEFT JOIN
* Subqueries
* Window functions: RANK(), DENSE_RANK(), ROW_NUMBER(), LAG(), and LEAD()
* Running totals and average calculations

Analysis Performed

* Retrieve and filter customer information.
* Categorize accounts based on their balances.
* Calculate total, average, highest, and lowest account balances.
* Compare savings and current accounts.
* Analyze deposit and withdrawal transactions.
* Identify accounts with balances above the average.
* Rank loans by loan amount.
* Calculate running totals for transactions and loans.
* Combine account and transaction information using joins.
* Identify accounts with the highest balances.

Key Learning Outcomes

* Improved practical SQL query-writing skills.
* Learned to structure and manage relational databases.
* Practiced analyzing banking data using aggregate functions and subqueries.
* Gained experience with joins and window functions.
* Developed the ability to retrieve meaningful information from structured datasets.
